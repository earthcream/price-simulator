# 価格波及シミュレーター

日本銀行「企業物価指数」の過去データから、**ある品目の価格が上がったとき、
それを原材料とする品目が「何ヶ月後に」「何%」上がるか**を実証的に示す静的サイト。
実行時にAI APIは使わない。

- **注目品目**（トップ）: 直近3ヶ月で異例な変動をした川上品目。値動きグラフと、今後影響が出る下流品目・時期
- **品目の値動き検索**: 直近1/3/12ヶ月の上昇・下落ランキングと、国内515＋輸入210品目の推移グラフ（`data/prices.json`、直近15年）
- **調達品目からの検索**: 品目→主要ドライバー（統計的に有意な上流品目）と「上流が◯%上がったら◯ヶ月後に◯%」
- **シミュレーター**: 上流品目と上昇率を入力→「◯ヶ月後に◯%（95%信頼区間）」を表形式で表示。
  直接の下流に加え、転嫁率15%以上の強いリンクをたどった2次・3次の連鎖波及（各段の応答を合成した点推定）も経路つきで表示

## データ

| ソース | 内容 | 期間 |
|---|---|---|
| `cgpi_m_jp.zip` | 企業物価指数2020年基準（国内515・輸出184・輸入210品目、月次） | 2020年1月〜最新 |
| `cgpilink2.csv` | 2020年基準接続指数（品目レベル、消費税を除く） | 1980年1月〜2019年12月 |
| `fm08_m_1.html` | 外国為替相場（ドル・円スポット月中平均） | 1973年1月〜最新 |

系列コードが両基準で共通のため、接続指数と現行系列を縦に結合して**最長559ヶ月**の系列を構築
（465/515品目が1980年から利用可能）。すべて日本銀行「時系列統計データ検索サイト」の公開データ。

## 手法

- **品目対応表**（`data/input_map.csv`）: 515品目それぞれに主原料候補3〜8個
  （輸入物価品目を含む）をサプライチェーンの知見で列挙。上流→下流の一方向のみ。
  人手でレビュー・修正可能なCSV。再生成は `scripts/build_input_map.py`
- **推定**（`scripts/estimate.py`）: ローカル・プロジェクション（Jordà 2005）で
  h=0〜12ヶ月の累積弾性値を推定
  - 変数は対数階差（月次変化率）。前年同月比は不使用
  - コントロール: ドル円レート、原油価格（輸入物価・原油・契約通貨ベース）、被説明変数の自ラグ
  - Newey-West標準誤差（ラグ=h+1）
  - 上昇局面・下降局面に分けた推定で非対称性を算出
  - ピーク時点で p≥0.1 または弾性値が負のペアは「推定不能」とし数値を出さない
  - 観測数120ヶ月未満は「サンプル不足」

## メール登録・印刷

- シミュレーターは初回のみメールアドレス登録が必要（ブラウザに記憶、以後は聞かない）。
  登録先はGoogle Apps Script → スプレッドシート「まとめてやるぜ」。設定は
  [docs/メール登録の設定手順.md](docs/メール登録の設定手順.md)、スクリプトは `gas/Code.gs`。
  `index.html` の `EMAIL_ENDPOINT` にウェブアプリURLを入れるまでは送信されない
- 各グラフの「印刷／PDF（A4一枚）」で、グラフ＋月別の表＋出典・注意書きを1枚に出力

## 更新

- 日銀の公表は毎月第8営業日ごろ。GitHub Actions（`.github/workflows/monthly-update.yml`）が
  毎月14日に fetch → estimate → `data/results.json` 更新 → push（GitHub Pagesが自動再デプロイ）
- 5年ごとの基準改定は自動対応しない → [docs/基準改定時の手動作業手順.md](docs/基準改定時の手動作業手順.md)

## ローカルでの実行

```bash
pip install -r requirements.txt
python scripts/fetch.py          # 日銀からデータ取得 → data/
python scripts/estimate.py       # 推定 → data/results.json
python scripts/export_prices.py  # 値動き検索用 → data/prices.json
python -m http.server 8000       # http://localhost:8000 を開く
```

## 公開（GitHub Pages）

1. このフォルダをGitHubリポジトリにpush
2. Settings → Pages → Source を「Deploy from a branch」/ `main` / `/ (root)` に設定
3. 月次更新はActionsが自動で行う（Settings → Actions → Workflow permissions を
   「Read and write permissions」にしておく）

## 免責

本サイトの数値は、日本銀行の企業物価指数をもとに、品目ごとの業界平均における
過去の値上がり・値下がりの波及パターンから推定した目安であり、個別の取引価格を示すものではありません。
出典: 日本銀行「時系列統計データ検索サイト」（企業物価指数・2020年基準／接続指数、外国為替相場）を
未来調達研究所株式会社が加工して作成。

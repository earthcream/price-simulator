# 年次データ（労務費）の更新手順

対象: 賃金構造基本統計調査（職種別賃金）と公共工事設計労務単価。
`.github/workflows/yearly-update.yml` が毎年3月1日と12月1日に自動試行する。
失敗するとGitHubからメール通知が届くので、以下を手動で行う。

## 公共工事設計労務単価（毎年2月中旬公表・3月適用）

1. 国交省の報道発表を探す（「令和◯年3月から適用する公共工事設計労務単価」）
   https://www.mlit.go.jp/totikensangyo/const/1_6_bt_000217.html
2. 報道発表PDFのURLを `scripts/fetch_annual_labor.py` の `ROMU_PDF` に設定
   - `label` / `year` / `url` を更新
   - `pages`: PDF内で「都道府県別・職種別の単価表」があるページ番号（0始まり）。
     例年は5ページ構成（47都道府県×約10職種ずつ）
3. `ROMU_NATIONAL_AVG` に新年度の全国全職種平均（加重平均）を1行追加
   （報道発表の「資料2 全国全職種平均値の推移」に記載）
4. ローカルで `python scripts/fetch_annual_labor.py` を実行して
   「47都道府県×50職種」前後になることを確認
5. commit & push

## 賃金構造基本統計調査（毎年3月公表・e-Stat DB反映は秋ごろ）

- 通常は自動で新しい年が増える（e-Stat DB 0003426315 に年が追加され次第）
- 職種分類が改定された場合は statsDataId が変わる可能性があるので、
  e-Stat で「賃金構造基本統計調査 一般_職種（小分類）DB」を検索して
  `WAGE_TABLE` を差し替える

## 毎月勤労統計（月次・自動）

- 統計ダッシュボードAPI経由（`scripts/fetch_wages.py`）。設定不要
- 失敗が続く場合は指標コード（`INDICATORS`）をダッシュボードで確認

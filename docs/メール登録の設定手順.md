# メール登録の設定手順（Google Apps Script）

シミュレーターを初めて開くときに1回だけメールアドレスを入力してもらい、
スプレッドシート「まとめてやるぜ」に1行追記する仕組み。登録済みかどうかは
ブラウザ（localStorage）に記憶するので、同じ人に二度は聞かない。

費用はゼロ。Apps Scriptの無料枠は1日あたり数万リクエストなので、月数千件でも問題ない。

## 1. Apps Script を作る

1. 対象のスプレッドシート（ID: `1wxOAYMw8zZfLwHx1T_lXk1rNeeOd0p-_xqP-Ea9c-xA`）を開く
2. メニュー「拡張機能」→「Apps Script」
3. エディタの内容をすべて消し、`gas/Code.gs` の中身を貼り付けて保存
4. 関数 `testAppend` を選んで「実行」→ 権限の承認ダイアログが出るので許可
   → シート「まとめてやるぜ」の末尾に `test@example.com` の行が入れば成功（行は消してよい）

## 2. ウェブアプリとしてデプロイ

1. 右上「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」
3. 次のユーザーとして実行：**自分**
4. アクセスできるユーザー：**全員**（サイト訪問者が匿名でPOSTするため）
5. 「デプロイ」→ 表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー

## 3. サイトにURLを設定

`index.html` の下記1行にURLを貼る。

```js
const EMAIL_ENDPOINT = "https://script.google.com/macros/s/XXXXX/exec";
```

空のままだと、登録画面は出るがシートには送らず、ブラウザに記憶するだけになる。

## 4. 動作確認

- ブラウザのシークレットウィンドウでサイトを開き、「シミュレーター」タブを押す
- メールを入力して登録 → スプレッドシートに行が追加されることを確認
- 列の並び：取得元（価格シミュレーション）/ 日時 / メールアドレス

## 補足

- スクリプトを修正したら「デプロイ」→「デプロイを管理」→「新バージョン」で更新しないと反映されない
- 登録状態を自分のブラウザで解除したいとき：開発者ツールのコンソールで
  `localStorage.removeItem("fp_email")` を実行
- サイト側は `mode: "no-cors"` で送るため、送信結果は画面に表示しない（失敗してもユーザーの操作は止めない）

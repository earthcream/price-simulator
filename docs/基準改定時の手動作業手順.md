# 基準改定（5年ごと）時の手動作業手順

企業物価指数は5年ごとに基準改定される（2020年基準の次は2025年基準。公表切替は
通常、基準年の2〜3年後）。基準改定は品目の追加・廃止・統合を伴うため、
**自動対応せず、以下の手順で手動更新する**。

## 切替のサイン

- 月次のGitHub Actionsが失敗する、または取得件数が大きく変わる
- 日銀の一括ダウンロードページ（https://www.stat-search.boj.or.jp/info/dload.html）で
  ファイル名・基準年表記が変わる（例: `cgpi_m_jp.zip` の中身が2025年基準になる）

## 手順

### 1. 新基準ファイルの確認

```bash
python scripts/fetch.py
```

を実行し、エラー箇所を確認する。チェックポイント:

- 系列コードのプレフィックス（現在は `PRCG20_`。新基準では `PRCG25_` 等になる見込み）
  → `scripts/fetch.py` の `KIND_MAP` 周辺と正規表現 `^PRCG20_(\d\d)` を修正
- 種類コード（22=国内、12=国内税抜、24/23=輸出、26/25=輸入)の割当が
  新基準でも同じか、ダウンロードしたCSVの先頭行で確認する

### 2. 接続指数（過去基準との接続）の確認

- 新基準の接続指数ファイル（現行の `cgpilink1.csv` / `cgpilink2.csv` に相当）が
  公表されるまでは、旧基準の接続指数と新基準系列の接続部で
  段差が生じないか `2019年12月→2020年1月` の検証と同様のチェックを行う
  （fetch.py 実行後に log差の分布を確認）

### 3. 品目対応表の更新

- 新基準で品目が追加・廃止・改称されるため、`scripts/build_input_map.py` を再実行し、
  「未解決」「ルールなし」と表示された品目についてルールを追加・修正する

```bash
python scripts/build_input_map.py
```

- 出力された `data/input_map.csv` を人手でレビューする
  （特に新設品目の上流候補と、改称品目の名前解決）

### 4. 再推定と確認

```bash
python scripts/estimate.py
```

- `有意ペア率` が従来（約50%）から大きく落ちていないか確認
- サイトをローカルで開き（`python -m http.server`）、代表品目
  （小麦粉・段ボール・事業用電力・乗用車など）の結果が経済的に妥当か確認

### 5. 表記の更新

- `index.html` のタイトル・注記にある「2020年基準」を新基準に変更
- `scripts/estimate.py` の `OIL_CODE`（輸入物価・原油・契約通貨ベース）の
  系列コードが新基準で変わっていないか確認

### 6. コミットとタグ

```bash
git add -A
git commit -m "2025年基準への切替"
git tag base-2025
git push --tags
```

## 注意

- 接続指数は「消費税を除く」系列（プレフィックス12）を推定に使っている。
  新基準でこの系列の提供形態が変わった場合は `KIND_MAP` の `domestic` の割当を見直すこと
- 旧基準の生データは `raw/` に残るが、gitには含めていない。
  切替前に一度 `raw/` のバックアップを取っておくと検証に便利
